# PetShop Amigo Fiel
Um projeto moderno e responsivo para PetShop Amigo Fiel, desenvolvido com foco em boas práticas de desenvolvimento front-end, escalabilidade e experiencia do usuário. Ideal para quem busca um ponto de partida sólido para projetos web institucionais

---

## ✨ Funcionalidades
- **Homepage** com hero section e chamada para açao
- **Seçao de Serviços** (banho, tosa, veterinário etc.)
- **Galeria de Imagens**
- **Formulário de contato** com  validaçao em JavaScript
- **Seçao de Localizaçao**
- **Menu Responsivo** para dispositivos móveis
- **Design limpo e moderno** com CSS customizado

---

## 🚀 Como executar
1. Clone este repositório
2. Abra a pasta `Projeto-Petshop` no seu editor ou navegador
3. Basta abrir o arquivo `index.html`em seu navegador preferido
